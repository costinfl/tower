# Roadmap

This roadmap describes the intended evolution of Tower.

It is directional rather than a fixed implementation plan.

---

# Milestone 1

Goal:

Provide a reliable operational view of software releases.

Capabilities:

- Release Packs
- Promotion Paths
- Environment observations
- Application versions
- Documentation generation

---

# Milestone 2

Potential improvements:

- Historical environment comparison
- Environment snapshots
- Richer release documentation
- Additional connectors

---

# Milestone 3

Potential improvements:

- Historical analytics
- Advanced visualizations
- Architecture evolution tracking
- AI-assisted operational summaries

Future milestones should only be pursued if they reinforce the project's primary mission.
